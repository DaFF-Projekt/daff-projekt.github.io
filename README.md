# Datenmanagement für die Feldforschung (DaFF)

*Ein Projektvorhaben im Rahmen der Landesinitiative Forschungsdatenmanagement Niedersachsen*

Das Projekt Datenmanagement für die Feldforschung (DaFF) entwickelt eine Blaupause für einen Felddatenmanager, um den Umgang mit Forschungsdaten aus Feldexperimenten grundlegend zu verbessern.
Im Mittelpunkt steht die Harmonisierung von Forschungsdaten und Befähigung von Forschenden in der Umsetzung des Forschungsdatenmanagements dieser Domäne.
Das Projekt greift dabei die besonderen Herausforderungen in der Feldforschung auf, deren Experimente oft unter wechselnden, nicht kontrollierbaren Feldbedingungen stattfinden und hohe technische Ressourcen binden.
Durch die Entwicklung eines strukturierten Datenmanagements werden diese aufwendigen Erhebungen besser dokumentiert, nachvollziehbar gemacht und für weitere Analysen nutzbar gemacht.
